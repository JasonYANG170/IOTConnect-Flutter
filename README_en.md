## Support system
**Android, HarmonyOS** devices
**Mac, IOS** devices
**Windows, Linux** devices
**Web** devices

## Native development version
[For Windows and Linux, please click here](https://github.com/JasonYANG170/IOTConnect-PC)
[For Android and HarmonyOS, please click here](https://github.com/JasonYANG170/IOTConnect-Android)

## Features
- ✅ Backend system
- ✅ Local saving of configuration information
- ✅ User login and registration
- 🚧 MQTT protocol remote device control
- 🚧 AI Chat interactive model linkage
- 🚧 Web Api to get daily weather
- 🚧 Smart reminder

## Supported devices
- 🚧 Flowerpot smart interactive flowerpot
- 🚧 YANG SSD smart display hard drive box
- 🚧 KeyBox key
- 🚧 OnlineAdmin remote control
- 🚧 AIChatBox smart assistant

Other developers are welcome to connect to our MQTT server
